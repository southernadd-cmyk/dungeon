# Dungeon Quest
An atmospheric, single-switch dungeon roguelike. Every action is a tactical choice; enemies never move while you are scanning.

## Play the expedition
Serve the repository root over HTTP (for example, python -m http.server) and open index.html. The dedicated title menu opens a short, visible and narrated prologue when you begin an expedition. Enter the crypt immediately, repeat the narration, or return to the menu. Continue restores the automatically saved expedition without replaying the intro, including blessings, enemy intentions and results. Choose Controls on the main menu or in Settings. In one-switch mode, Enter (including numpad Enter) selects the automatically highlighted choice on release; Space is the scan brake when enabled. In two-switch mode (the shared default), Space advances and Enter selects on release; held Space optionally scans backwards. Switching to two switches requires confirmation. Scan and speech preferences use the NARBE shared managers, with five scan intervals and voice selection. Same-origin Hub settings can be shared; standalone hosting uses its own origin storage. Mouse and touch also work. Reduced motion and sound effects remain game-local. All choice targets are at least 64 CSS pixels tall. Same-origin Hub visual preferences (highlight colour and style, text colour, background theme and UI size) are inherited from the Hub's settings record; conflicting colour combinations are adjusted for readability. Standalone play retains the default presentation unless the same origin provides that record. Narrow and short landscape screens adapt without changing scan order; OS forced-colour mode retains a distinct outline. Pause is a selectable action during any turn or result; Continue, Restart, Settings, Main menu, Exit game and Help do not advance gameplay. Restart and Reset progress require a separate confirmation. Exit game sends the Hub's focusBackButton message when embedded; standalone exit safely returns to the main menu. Progress is saved locally after entering the crypt and after every committed gameplay action. Closing or reloading on the same browser origin restores the last saved turn. Save failures are visible and spoken; incompatible saves cannot crash the game. Restart and reset clear only the expedition, not accessibility preferences. No reaction-time challenge.

Explore three floors: the Forgotten Crypt, the Bone Vault and the Bellkeeper's Sanctum. Enemies announce their strikes, and guarding reduces the damage and counters before a recovery opening. Treasure supplies gold and draughts. Choose one of three permanent or restorative blessings between floors. Defeat the Bellkeeper and claim the Bell of Dawn to win. Inspect surroundings without taking a turn. Floor layouts and encounters are deterministic for a seed; four room silhouettes, variable doorways and optional extra connections keep the map compact but varied. Travel toward treasure, stairs or the final boss combines ordinary movement turns in a single selection and stops at danger or an interactable objective. It never opens treasure, fights or descends automatically.

## Architecture
- engine.js: deterministic simulation and legal action enumeration; no DOM or timers.
- art.js: original procedural Canvas 2D artwork, depth sorting and optional atmospheric effects.
- app.js: switch scanning, speech, UI and preference persistence.

The renderer is dependency-free for this initial slice. The choice and voice layers use an unmodified, pinned MIT-licensed snapshot of NARBE shared modules (see vendor header). Hub packaging, physical switch validation remain outstanding. Artwork is an original procedural first pass, not a completed sprite pack.

## Development
Run node --test tests/*.test.js. A single quick CI job checks syntax and engine tests. GitHub Pages can serve the root without a build step once configured.
